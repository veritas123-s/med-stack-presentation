# Med Stack 项目路演

面向医学院团委老师的 HTML 演示网站，包含 18 页主讲和 2 页备查附录。

网站：https://veritas123-s.github.io/med-stack-presentation/

## 使用

方向键、空格、鼠标滚轮或底部按钮切页；M 打开目录，F 全屏，N 显示讲述提示。每页“依据”可查看来源。

也可以下载仓库，直接打开 index.html；无需安装依赖。

## 内容与维护

页面内容和交互位于 app.js，样式位于 styles.css。更改 main 分支后，GitHub Pages 会重新发布。

数据核对日期：2026-10-01。现有功能、测试记录、团队自述和后续规划已分别标注；Hades 工作流使用合成示例。

本仓库仅保存演示网页，不包含 Hades 程序、账号、密钥或个人运行数据。
